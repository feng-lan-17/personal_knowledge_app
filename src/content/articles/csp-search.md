## 图只先记两种存法

点从 \(0\) 到 \(n-1\)，边是一对点。邻接表适合大多数题：

```cpp
#include <vector>
using namespace std;

vector<vector<int>> graph(n);
void add_edge(int u, int v) {
    graph[u].push_back(v);
    graph[v].push_back(u); // 无向边才需要这一行
}
```

点数很小、需要很快判断两点是否相连时，才用邻接矩阵。矩阵是 \(O(n^2)\) 的空间，\(n\) 到几千就不要用。

## 广度优先搜索：先到的层更近

在无权图上，从起点一层层扩展，第一次到达某个点的步数就是最少步数。队列负责“现在这一层”。一个点入队时就标记已访问，而不是出队时才标记，否则同一个点会进队很多次。

```cpp
#include <queue>
#include <vector>
using namespace std;

vector<int> bfs(const vector<vector<int>>& graph, int start) {
    int n = static_cast<int>(graph.size());
    vector<int> dist(n, -1);
    queue<int> q;
    dist[start] = 0;
    q.push(start);
    while (!q.empty()) {
        int u = q.front();
        q.pop();
        for (int v : graph[u]) {
            if (dist[v] != -1) continue;
            dist[v] = dist[u] + 1;
            q.push(v);
        }
    }
    return dist;
}
```

格子上的马也可以用同一类搜索。马走日字，八个方向是：

```cpp
const int dx[] = {1, 1, -1, -1, 2, 2, -2, -2};
const int dy[] = {2, -2, 2, -2, 1, -1, 1, -1};
```

洛谷 P1443 的题面用的就是这种步法，数据范围和障碍以原题为准：[P1443](https://www.luogu.com.cn/problem/P1443)。上面的数组只说明方向，不是一份提交用的完整程序。

深度优先搜索则是一条路走到不能走再回头。它适合“所有方案”“连通块”，不适合在无权图上求最短路。递归忘记标记访问，会沿着环走个不停。

## 动态规划：先写“最后一个选择”

不要从名词开始。找一个最小的例子，问：最后一步是什么，剩下的部分是否更小。

数字三角形可以用自拟的三行看这个问法。这不是任何比赛题的样例：

```text
1
2 3
7 4 5
```

若走到最底层的某个位置，它只能从左上或右上来。令 `f[i][j]` 为走到第 `i` 行第 `j` 个数的最大和，则

```cpp
f[i][j] = g[i][j] + max(from_left, from_right);
```

不存在的那一侧就不要参加 `max`。这样从顶算到底，最后一行的最大值就是答案。时间与格子数成正比。洛谷 P1216 是同一类练习的真实入口：[P1216](https://www.luogu.com.cn/problem/P1216)。

0/1 背包是另一种“最后一件拿不拿”。容量 `W`，每件物品最多一次。用一维数组时，容量要从大到小更新，否则同一件会被用两次。自拟数据：容量 5，物品 `(重量 2, 价值 3)` 和 `(重量 3, 价值 4)`。两种都拿刚好是 5 和 7；只拿第二件是 4。正确答案是 7。洛谷 P1048 是 0/1 背包的一个真实入口：[P1048](https://www.luogu.com.cn/problem/P1048)。P1049 是另一道相近的装箱练习：[P1049](https://www.luogu.com.cn/problem/P1049)。都不要把网上的整份题解贴进自己的笔记还当作自己会了。

## 和 300 分这个说法的关系

认证没有公开的“做到这里就有 300 分”的清单。模拟、排序、二分、简单搜索和一维或二维的简单规划，是许多人在冲这个分数时反复遇到的种类。遇到图论里更重的算法、字符串自动机或复杂的数论时，可以先确认那一题是不是你当前卷子里的高档题，再决定要不要读。本库这一版停在上面这些概念，不往下堆专题。

## 常见错误

- BFS 出队才标记，队列被重复点撑大。
- 最短路误用 DFS。
- 背包容量从小到大，物品被重复使用。
- 递归深度过大却没有改成循环。格子很大时，手写栈或改 BFS 更稳。
- 把题解网站上的代码整段抄来，变量和题面对不上。
