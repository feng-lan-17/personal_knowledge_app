## 需要随身带着的数学

把一个 token 想成一条向量。两条向量的点积大，表示它们在这个空间里更同向。点积本身没有“重要”的单位，后面要把它变成权重，才用得上 softmax。

softmax 把一排实数变成非负、加总为 1 的权重：

$$
\mathrm{softmax}(z)_i = \frac{e^{z_i}}{\sum_j e^{z_j}}
$$

编程时如果直接算指数，分数很大时会溢出。教学实现里先减去最大值，结果不变，数值更稳。交叉熵则用来比较“模型给出的分布”和“真实的下一个 token”。损失变小，只说明这个预测更接近训练文本。

## 需要随身带着的编程

你至少要能读懂张量的形状。一批句子、每句若干 token、每个 token 一条 \(d\) 维向量，形状常写成 `(batch, time, d)`。矩阵乘错了，错误会表现为形状对不上，而不是一句看不懂的文辞。下面的例子故意只用二维，方便对着公式看。

```python
import numpy as np

def softmax(z):
    z = z - np.max(z, axis=-1, keepdims=True)
    exp = np.exp(z)
    return exp / np.sum(exp, axis=-1, keepdims=True)

def attention(q, k, v):
    d = q.shape[-1]
    scores = q @ k.T / np.sqrt(d)
    weights = softmax(scores)
    return weights @ v, weights
```

这是单头、没有 mask 的教学实现。它不会在本程序里执行。框架里的函数还会处理批、多头和因果掩码，那些参数随版本变化，以你安装的文档为准。

## 从机器学习到这一层

机器学习的共同部分，是用数据调整参数，使某个损失变小。深度学习把这个调整做在多层可微的函数上。语言模型把“预测下一个 token”当成那个损失。循环网络按时间一步步走，长序列上平行度差，远处的信息也不容易留下来。Transformer 换成自注意力：每个位置可以直接看其他位置，计算更方便平行。

Vaswani 等人 2017 年的论文把整套编码器和解码器都建成注意力加前馈，不再使用循环和卷积作为主干。今天的大语言模型多用其中的解码器栈，并加上因果掩码，让位置 \(i\) 看不见它后面的 token。论文里的翻译实验设置不是现在某个聊天产品的配置，读的时候把“结构”和“当年的超参数”分开。

## 缩放点积

查询、键、值分别是矩阵 \(Q\)、\(K\)、\(V\)。论文中的缩放点积注意力是：

$$
\mathrm{Attention}(Q,K,V)=\mathrm{softmax}\left(\frac{QK^{\mathsf T}}{\sqrt{d_k}}\right)V
$$

除以 \(\sqrt{d_k}\)，是因为维度变大以后点积的数值会变大，softmax 会过于尖，梯度变差。多头是把向量拆成几组，各自做一次注意力，再拼回去。这样不同的头可以留意不同的对应关系。你不需要在第一遍就记住头的个数。先记住：权重来自查询和键的匹配，输出是值的加权和。

掩码的做法，是在 softmax 之前把不允许看见的位置设成一个很大的负数。那些位置的权重就会接近 0。

## 一层里还有什么

注意力的输出会加上输入本身，这叫残差，然后做层归一化。接着是一个对每个位置单独作用的前馈网络，再来一次残差和归一化。堆很多这样的层，就得到模型的主干。图见前一篇文章里的那张简图，名字可以对上。

位置信息要另外加进去，否则自注意力本身不太区分“谁在前”。早期论文用固定的正弦位置编码，后来的模型有的改用可学习的位置，或在注意力里使用相对位置。这是版本敏感的部分：读具体模型时再核对它用的是哪一种，不要把 2017 年图上的正弦公式当成所有模型的现状。

## 训练、微调、评估

预训练在大量文本上做下一个 token 的预测，得到一组通用权重。微调是在这组权重上继续用较小的、目标更明确的数据更新。指令微调让模型更常按要求的格式回答；偏好类方法则试图让它更常选择某一类回答。这些名字描述的是数据和方法，不是质量保证。

评估不能只看“读起来像不像”。至少分开看：闭卷事实是否核对过、计算是否可复现、有没有引用它不该看见的材料、长上下文的中段是否还在。一个榜单分数是某套题目、某个日期的结果，过期就只能当历史，不能当当前能力。

## 推理和部署在概念上要分开的词

推理是用已经训好的权重往下生成。部署是把这些权重量到可运行的环境里。KV cache 是把已经算过的键和值存下来，避免每生成一个 token 都从头重算，它是实现上的加速，不改变“看不见窗口外内容”这件事。量化是用更少的位数保存权重，省内存，也可能损质量。具体用哪种位数、哪家推理引擎，随版本变化很大，本篇不写死命令。
